# TC-SUB-006: Trừ số âm

## Requirement ID
FR-CALC-002

## Module / Test type / Technique
Subtraction / Functional / Equivalence Partitioning

## Preconditions
- User đang ở trang Basic Calculator
- Build được chọn là "Prototype"

## Test data
| Field | Value |
|-------|-------|
| First number | 5 |
| Second number | -3 |
| Operation | Subtract |

## Test steps
1. Nhập "5" vào ô First number
2. Nhập "-3" vào ô Second number
3. Chọn Operation là "Subtract"
4. Bấm nút "Calculate"

## Expected result
Ô Answer hiển thị kết quả là "8" (5 - (-3) = 8).
