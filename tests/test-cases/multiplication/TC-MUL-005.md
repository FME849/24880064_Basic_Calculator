## Requirement ID
FR-CALC-003

## Module / Test type / Technique
Multiplication / Functional / Equivalence Partitioning

| Field | Value |
|-------|-------|
| First number | 2.5 |
| Second number | 4.2 |

2. Nhập "4.2" vào ô Second number
3. Chọn Operation là "Multiply"
4. Bấm nút "Calculate"

Ô Answer hiển thị kết quả là "10.5".
