# TC-GUI-002: Label và placeholder hiển thị đúng

## Requirement ID
NFR-GUI-001

## Module / Test type / Technique
GUI / GUI Testing / Checklist

## Preconditions
- User đang ở trang Basic Calculator
- Build được chọn là "Prototype"

## Test data
Không có dữ liệu test cụ thể.

## Test steps
1. Mở trang Basic Calculator
2. Kiểm tra các label:
   - "Build" label bên cạnh dropdown build
   - "First number" label bên cạnh ô nhập số 1
   - "Second number" label bên cạnh ô nhập số 2
   - "Operation" label bên cạnh dropdown phép toán
   - "Answer" label bên cạnh ô kết quả
   - "Integers only" label bên cạnh checkbox

## Expected result
Tất cả label hiển thị đúng text, đúng vị trí, font chữ rõ ràng và dễ đọc.
