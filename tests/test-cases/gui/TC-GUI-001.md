# TC-GUI-001: Hiển thị đầy đủ các thành phần giao diện

## Requirement ID
NFR-GUI-001

## Module / Test type / Technique
GUI / GUI Testing / Checklist

## Preconditions
- User đang ở trang Basic Calculator
- Lần lượt chọn từng Build để test: Prototype, 1, 2, 3, 4, 5, 6, 7, 8, 9

## Test data
Không có dữ liệu test cụ thể.

## Test steps
1. Mở trang Basic Calculator
2. Quan sát và kiểm tra sự hiện diện của các thành phần:
   - Dropdown "Build"
   - Tiêu đề "Calculate"
   - Ô nhập "First number"
   - Ô nhập "Second number"
   - Dropdown "Operation"
   - Nút "Calculate"
   - Ô "Answer"
   - Checkbox "Integers only"
   - Nút "Clear"

## Expected result
Tất cả 9 thành phần giao diện đều hiển thị đầy đủ, rõ ràng, và có thể tương tác được.
