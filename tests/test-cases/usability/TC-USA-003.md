# TC-USA-003: Nhập số bằng bàn phím

## Requirement ID
NFR-USA-001

## Module / Test type / Technique
Usability / Usability Testing / Exploratory Testing

## Preconditions
- User đang ở trang Basic Calculator
- Lần lượt chọn từng Build để test: Prototype, 1, 2, 3, 4, 5, 6, 7, 8, 9

## Test data
| Field | Value |
|-------|-------|
| First number | 123 |
| Second number | 456 |

## Test steps
1. Click vào ô First number
2. Nhập "123" bằng bàn phím
3. Bấm Tab để chuyển sang ô Second number
4. Nhập "456" bằng bàn phím
5. Kiểm tra giá trị hiển thị trong cả hai ô

## Expected result
- Các ô input nhận và hiển thị đúng giá trị được nhập từ bàn phím
- Có thể nhập số, dấu chấm thập phân, dấu trừ (số âm)
- Cursor hiển thị đúng vị trí khi đang nhập
